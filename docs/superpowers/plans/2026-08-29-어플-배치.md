# 폰 화면을 어플 배치로 바꾸기 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰 폭에서 아이SHADOW를 하단 탭바가 있는 어플 배치로 바꿔, 한 화면에 실린 글을 줄인다. 데스크톱은 건드리지 않는다.

**Architecture:** DOM을 옮기지 않는다. 섹션마다 `data-tab-of` 표시만 붙이고, `<html data-tab>` 값에 따라 **맞지 않는 섹션만** CSS로 숨긴다. 모든 규칙은 `@media (max-width: 560px)` 안에 있어 데스크톱에는 아예 적용되지 않는다. 탭바는 진짜 `<a href="#…">` 링크라 JS가 죽어도 이동은 된다.

**Tech Stack:** 순수 HTML/CSS/JS 한 파일(`index.html`), 빌드 도구 없음. 테스트는 Playwright 스크립트(`node test/<파일>.js`).

**Spec:** `docs/superpowers/specs/2026-08-29-어플-배치-design.md`

- **한글이 든 스크립트는 셸 heredoc으로 만들지 마세요.** 깨진다. Write 도구를 쓴다. 한글 경로도 bash에서 깨지므로 스크립트 안에 절대경로로 박는다 (AGENTS.md 6절).
- **새 색을 만들지 마세요.** 추가하는 토큰은 `--accent-bar: #f4d95c` 하나뿐이다. `--accent: #f0cb00`은 그대로 둔다.
- **근거 산문을 지우거나 다시 쓰지 마세요.** 접기만 한다. 점수·막대는 접힌 상태에서도 항상 보인다.
- **채점·마스크·프롬프트 로직을 건드리지 마세요.** 이번 변경은 배치와 표시뿐이다.
- **커밋은 사용자가 요청할 때만.** AGENTS.md 7절. 각 과제 끝의 커밋 단계는 **사용자에게 물어본 뒤**에만 실행한다. 커밋 전에는 항상 `bash scripts/check-secrets.sh`.

/* ── 어플 배치 (폰 폭 전용) ─────────────────────────────────────────────
   섹션을 DOM에서 옮기지 않는다. 옮기면 리사이즈마다 되돌려야 하고
   position:sticky와 ScrollTrigger가 꼬인다 — ScrollSmoother로 sticky를
