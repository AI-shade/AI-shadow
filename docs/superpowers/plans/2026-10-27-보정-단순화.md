# 보정 화면 단순화 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 누운 사진을 사용자가 돌릴 수 있게 하고, 보정을 «배경 교체 / 옷 교체» 두 개로 줄이며, 배경 교체를 사람을 마스크로 막는 fill 방식으로 바꾼다.

**Architecture:** 프론트는 `index.html` 한 파일(빌드 없음). 배경 교체는 옷 교체가 이미 쓰는 경로(마스크 PNG + `compositeThroughMask`)를 그대로 따르고, 서버 `/api/replace-background`는 kontext 대신 `fal-ai/flux-pro/v1/fill`을 부른다. 빠지는 방식의 내부 함수는 남기고 화면에서 부르는 곳만 끊는다.

**Tech Stack:** 바닐라 JS, Express(ESM), fal.ai, MediaPipe, face-api.js, Playwright 테스트.

## Global Constraints

- 설계: `docs/superpowers/specs/2026-10-27-보정-단순화-design.md`
- 마스크: 흰색 = AI가 다시 그림, 검은색 = 보존. 얼굴·손을 검게 덮는 것이 언제나 마지막 단계.
- 원본을 보내는 경로는 누를 때마다 `askFluxConsent()`.
- 배경 교체 전송 크기: 긴 변 1024px, 32의 배수. 옷 교체는 기존 `FAL_MAX_SIDE`(1568) 그대로.
- 사진 방향은 AI가 판단하지 않는다.
- fal.ai·Claude를 실제로 부르는 테스트는 돌리지 않는다(사용자가 직접 테스트).
- 저장소는 CRLF. 커밋은 사용자가 요청할 때만.
- 테스트는 `http://localhost:8000` 정적 서버를 본다: 저장소 루트에서 `python -m http.server 8000`.
