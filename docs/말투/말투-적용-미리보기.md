# 말투 규칙 적용 미리보기

[말투-규칙.md](말투-규칙.md)를 지금 웹페이지 문구에 적용하면 어떻게 바뀌는지 보여 주는 비교표입니다.
**index.html은 고치지 않았습니다.** 이 표는 보기용입니다.

- 기준: 깃허브 `origin/main`(ef8cb50, 2026-11-21 hyeonmi300)의 `index.html`
- 화면에 보이는 글 1,128조각 중 규칙에 걸린 것: 약 230조각. 이 표에는 화면에 실제로 나오는 문장 단위로 묶어서 실었습니다.
- «줄»은 위 버전 `index.html`의 줄 번호입니다.
- `{이름}`, `{N}`처럼 중괄호로 쓴 곳은 사진마다 바뀌는 값입니다.
- 규칙 번호는 말투-규칙.md의 절 번호입니다.
- 뜻과 사실 범위는 바꾸지 않았습니다. 사실이 맞는지 사람이 봐야 하는 곳은 **확인 필요**로 표시했습니다.

- **화면에 안 나오는 글:** 디버그 화면(?debug=1), console 기록, AI 재검증에 보내는 처리 설명(`lastCorrectionMeta.detail`).

## 이 표를 만들면서 나온 것

- **같은 것을 다른 이름으로 부르는 곳:** «같은 이미지 발견»과 «같은 사진이 인터넷에 있음», «재검증»과 «검증»과 «다시 검사». 표에서는 «사진», «다시 검사»로 맞췄습니다.
- **«배경 교체하기»(4062)와 «배경 전체 바꾸기»(4066)** 단추가 함께 있습니다. 둘이 어떻게 다른지 이름만으로는 알기 어렵습니다. 말투가 아니라 이름 문제라 바꾸지 않았습니다.
- **보정 결과 안내에 «(약 $0.04, 12초)»처럼 달러 비용이 나옵니다.** 부모에게 보여 줄 정보인지 정해야 합니다. 말투 규칙에는 없어서 그대로 두었습니다.
- **«세 단계», «다섯 가지», «사진 한 장»** 같은 숫자 풀어 쓰기는 7절에 맞춰 «3단계», «5가지», «1장»으로 바꿨습니다. 소개 화면에서 어색하면 팀이 예외로 정할 수 있습니다.
